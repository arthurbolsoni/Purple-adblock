### Playlist rewrite drops tags

`Player.onFetch` passes every playlist through `mergeM3u8Contents`, even without ads. Probe: an fMP4 playlist with `EXT-X-VERSION`, `EXT-X-MAP`, `EXT-X-PROGRAM-DATE-TIME` and `EXT-X-TWITCH-PREFETCH` came out with only `EXTM3U`, `TARGETDURATION`, `MEDIA-SEQUENCE`, `EXTINF` (no comma) and URIs.

### Page fetch hook

`index.ts` reads every page response as text and builds a new `Response`. Node: `new Response("", { status: 204 })` throws `Invalid response status code 204`. Binary bodies are decoded as UTF-8.

### Router

`url.includes(null)` is `true` for `".../hls/nullbyte.m3u8"`: routes without `ignore` skip channels whose name contains `null`.
