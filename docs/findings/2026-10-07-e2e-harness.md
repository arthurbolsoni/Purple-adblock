# Level 3 harness on twitch.tv: hidden desktop, page selectors, worker log, first L3-01 runs

Date: 2026-10-07 · Edge 154.0.4258.62, nodriver 0.50.3, Python 3.14.2 · profile `~/nodriver/profile-edge-purple`, logged out · build: branch `melhorias-bloqueio` at 3d6c4f4 (worker code after T-001 to T-003) · Used by: T-004, T-103, T-104, T-111, L3-01

## Method

- `e2e/lib.py` starts Edge on a separate hidden Win32 desktop (`CreateDesktopW`, `STARTUPINFO.lpDesktop`), connects nodriver to its CDP port, turns on focus emulation and adds `e2e/recorder.js` (and, in userscript mode, the built userscript) with `Page.addScriptToEvaluateOnNewDocument`.
- `e2e/recorder.js` wraps the native `Worker` (same checks as [worker injection race](2026-10-04-worker-injection-race.md)) and prepends a logger to every worker script. The logger reports through a `BroadcastChannel`: each `fetch` the worker makes on the network, each `fetch` result the player gets once Purple has replaced `self.fetch`, Purple's console lines, console errors, uncaught errors and unhandled rejections. URLs are logged without the query string; bodies are not read.
- `probes/twitch_ui_probe.py` lists the `data-a-target` values around the player and the worker scripts, in record mode (no Purple), on: a channel from `/directory/all`; the same with every worker `fetch` to `*.ttvnw.net` rejected (`--block-video`); a channel from a mature-rated category (`/directory/category/grand-theft-auto-v`).
- `python e2e/run.py L3-01`: run A, both modes, before the worker log existed; run B, extension mode; run C, userscript mode. Every run picked the same channel, the first card on `/directory/all`.

## Results

### Hidden desktop

In record mode the channel played on the hidden desktop: `readyState 4`, `currentTime` from 4.8 to 20.9 s over 16 s, ad overlay shown during the preroll and gone by 24 s.

### Page selectors (`e2e/twitch_selectors.py`)

| Selector | Seen when |
| --- | --- |
| `a[data-a-target="preview-card-image-link"]` | channel cards on `/directory/all` and on a category page |
| `[data-a-target="video-ad-label"]`, `[data-a-target="video-ad-countdown"]` | preroll without Purple (at 8 and 16 s, gone at 24 s) |
| `[data-a-target="player-overlay-content-gate"]` | worker `fetch` to `*.ttvnw.net` rejected: "There was a network error. Please try again. (Error #2000)" and "Click Here to Reload Player", `readyState 0` |
| `[data-a-target="content-classification-gate-overlay"]` | channel in a mature-rated category, logged out: the overlay only has "log in" and "create an account" buttons; `readyState 0` for 24 s |

A logged-out viewer cannot pass the content classification gate, so L3-01 skips gated channels (up to 8 directory cards).

`Network.setBlockedURLs(['*.ttvnw.net*'])` on the page session did not reach the player worker's requests: no error overlay within 24 s. The probe rejects them inside the worker instead.

### Player workers

Every player worker ran a 98-byte blob script: `importScripts('https://assets.twitch.tv/assets/amazon-ivs-wasmworker.min-<hash>.js')`. Two workers on a direct load, one after client-side navigation. L3-01 counts a worker as a player worker when its script contains `amazon-ivs-wasmworker`.

### Dedicated profile

The profile holds seven extensions: the Purple 2.6.7 store build and six that these tests never installed (Phantom, Keplr, Fin Wallet For Sei, Nodepay, uBlock Origin and one named `__MSG_appName__`). Inferred: they came from the Windows Microsoft account through Edge sync. Extension mode still enables only the unpacked build ([edge-nodriver](2026-10-03-edge-nodriver.md)). Every launch now adds `--disable-sync`.

### Worker log of the broken runs (B and C)

- The player requested the master from `usher.ttvnw.net/api/v2/channel/hls/<channel>.m3u8` in every load. Purple's usher route is `usher.ttvnw.net/api/channel/hls/`, so `onChannel` never ran and no `Stream` was stored for the channel.
- Media playlists were on `sae11`, `sae12` and `sae13.playlist.ttvnw.net` under `/v1/playlist/<opaque>.m3u8`, which Purple's `ttvnw.net/v1/playlist/` route matches.
- Media playlist requests from the player failed with `TypeError: Cannot read properties of undefined (reading 'getStreamByStreamType')` at `Player.fetchm3u8ByStreamType`, called from `Player.onFetch`. That code is reached only when `hasAds` is true for the playlist (logged-out preroll), and `currentStream()` is undefined because no `Stream` exists.
- The player then logged `Player stopping playback - error MediaPlaylist:9 (ErrorNetworkIO code 0 - Cannot read properties of undefined (reading 'getStreamByStreamType'))` and the page showed Error #2000. In run C the error reached the player twice per load without the overlay; the direct load kept playing and the client-side navigation stopped at 0 s.

## Consequences

- C-03 (T-103) breaks playback on twitch.tv today: when Purple's code runs in the player worker and the media playlist has ad markers, the hook throws and the player stops. Inferred for 2.6.7: same usher route and same code path.
- The injection race (C-11) varies: the extension's hook was installed at 1426 ms (in time) and at 3020 ms (late) on two direct loads. The userscript, added at document start, was always in time.
- Q-014: the `readyState 0` runs of 2026-10-04 match this path (Purple in the worker, stalled player); they were not logged.
- Q-005: the page's usher path is v2. The full query is still not recorded.
- Q-013: media playlists are on `<edge>.playlist.ttvnw.net`. Inferred: the masters list variants on that host, which Purple's variant regex (`https://video…`) does not read (T-104).
