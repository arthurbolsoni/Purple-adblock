# What `bun test` supports for this repo

Date: 2026-10-03 · Bun 1.4.1 · Used by: T-001, `docs/tests.md`

## Method

Throwaway test files with `bunfig.toml` and a preload, run with `bun test`.

## Results

| Check | Result |
| --- | --- |
| Legacy decorators (`experimentalDecorators` in `tsconfig.json`) | work |
| `jest.useFakeTimers()` + `jest.advanceTimersByTime()` from `bun:test` | work |
| `?raw` import through a `Bun.plugin` in the preload | works |
| Globals `fetch`, `Response`, `addEventListener` | present |
| `Bun.YAML.parse` | present |
| `jest.isolateModules`, `jest.resetModules` | absent |
| Dynamic import with a query string (`./x.ts?a`, `./x.ts?b`) | gives separate module instances, but not of their imports |
| `new Response("", { status: 204 })` | accepted (browsers and Node throw) |

## Consequences

- Route and message registration must be explicit (`createRouter`, `bindMessages`, `bootstrapWorker(scope)`) so tests build fresh instances.
- Page-hook tests assert identity and `bodyUsed`, not constructor errors.
